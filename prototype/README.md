# Design prototype

A single HTML file with fake data, used to judge the look and feel before building the real app. It is not the product and is not maintained. Open `index.html` in a browser.

Keys 1 to 9 switch scenes: Ambient, Listening, Thinking, Speaking, Timers, Ringing, Power, Music, Home. The Humour and Honesty sliders change the wording.

The real app is in `../app`.
